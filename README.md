# Kanban Task Management Application

A responsive Kanban-style task management web application that allows users to organize tasks across multiple boards and columns.

## Features

- Create, edit, and delete boards
- Create, edit, and delete tasks
- Organize tasks using Kanban columns
- Drag and drop tasks between columns
- Subtasks support
- Responsive design for desktop and mobile
- Dark and light theme support
- Local storage support for saving data

## Technologies Used

- HTML
- CSS
- JavaScript

## Application Sections

### Boards
Users can:
- Create new boards
- Switch between boards
- Edit board names and columns
- Delete boards

### Tasks
Users can:
- Add tasks
- Edit task details
- Delete tasks
- Add subtasks
- Track task progress

### Columns
Typical Kanban workflow includes:
- Todo
- Doing
- Done

Tasks can be moved between columns using drag-and-drop functionality.

##How to Run the Project

- Clone the repository:git clone https://github.com/menal00/Kanban-style-task-management-application.git
